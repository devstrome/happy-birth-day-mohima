# A little celebration for Mohima

A mobile-first birthday keepsake with the supplied photos, a 3D-style cake and wish interaction, and a homemade chime version of “Happy Birthday.”

## Run locally

```bash
npm install
npm run dev
```

## Sharing preview

The page includes Open Graph and large-image social metadata, and `public/opengraph-image.png` is the pink cake preview. Set `NEXT_PUBLIC_SITE_URL` to the deployed HTTPS address in the hosting environment. Messenger and other link scrapers need to reach that public address before they can show the preview.
